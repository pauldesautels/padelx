# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected vulnerability or for
material that may contain credentials, private user data, or exploitation
details.

Report security concerns privately to `support.padelx@gmail.com`. Include only
the minimum information needed to reproduce the issue, and do not access,
download, modify, or retain another person's data while investigating.

The public visibility of this repository does not grant permission to test
PadelX systems, accounts, infrastructure, or users without prior written
authorization.

## Supported versions

PadelX is currently preparing its first production release. Security fixes are
applied to the current release line; older builds may be unsupported.
