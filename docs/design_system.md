# PadelX mobile visual system

PadelX is dark-first, athletic, social, and restrained. Bright brand green is
an accent for primary action, selection, progress, and short brand moments—not
a large default surface.

- **Palette:** near-black green background; layered deep-green surfaces; muted
  borders; white primary text; grey-green secondary text; deep green primary
  action; bright PadelX green accent. Warning and destructive colors are used
  only for those meanings.
- **Teams:** Team 1 uses accessible sky blue; Team 2 uses soft violet. Textual
  team names and state labels always accompany color.
- **Type:** 34 display, 26 screen headline, 22 section headline, 20/16 card
  titles, 16/14 body, 12 metadata. Weight and spacing establish hierarchy.
- **Spacing:** 4, 8, 12, 16, 24, and 32 point steps. Screen margins are 20.
- **Shape:** 12-point controls, 16-point cards, and 22-point feature surfaces.
  Pills are reserved for compact status, not general layout.
- **Buttons:** deep-green filled primary; quiet outlined secondary; text for
  tertiary actions; coral destructive styling only after clear confirmation.
- **Surfaces:** hierarchy comes from tone, spacing, and typography before
  borders. Cards should not become a grid of outlined capsules.
- **Quick Match:** flagship surfaces use compact brand accents, team-grouped
  lobbies, explicit progress, and a clear next action.
- **Reliability:** always textual (`Reliability 95%` or `New player`), quiet,
  and separate from skill. It never uses simplistic good/bad-person colors.
